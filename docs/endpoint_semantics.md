# Endpoint semantics: five different questions, five different claims

Every behavioral number in this project is produced by one of a small number of
measurements. They are not interchangeable, they license different claims, and
the completed studies did not all measure the one their prose implied. This
document says exactly what each one is, which one Anthropic's systematic
evaluation uses, and which completed experiment measured which.

The machine-readable version is
[`artifacts/endpoint_audit/endpoint_claim_ledger.json`](../reports/endpoint_audit/endpoint_claim_ledger.json);
the audit that produced it is
[`endpoint_semantics_audit.md`](../reports/endpoint_audit/endpoint_semantics_audit.md).
Both are regenerated by `python scripts/write_endpoint_audit.py` and a test
fails if they drift from the code.

## The five measurements

### 1. Conditional sequence likelihood

Append a candidate's token sequence to the prompt, run one forward pass, and sum
the log-probability the model assigned to each of those tokens at the position
before it.

```
score(" microwave") = log p(" mi" | prompt)
                    + log p("cro" | prompt, " mi")
                    + log p("wave" | prompt, " mi", "cro")
```

`jlens.mmpilot.capability.score_candidate_sequences`.

**What it licenses.** A statement about how probable the model considers that
continuation. A *change* in it under an intervention is a real, controlled
causal effect on a likelihood.

**What it does not license.** Anything about what the model would emit. The
scored input is longer than the prompt: positions the model never chose were
forced into its context.

### 2. Restricted-candidate argmax

Score every candidate in a **supplied set** by (1), and call the highest-scoring
one the "prediction".

`jlens.mmpilot.capability.prediction_and_margin`.

**What it licenses.** A forced-choice preference among the candidates you handed
it. With six options named in the prompt, "the model selected `cat`" means "of
those six, `cat` scored highest".

**What it does not license.** "The model answered `cat`". "`cat` was the model's
output." "`cat` was top-1." The other ~262,000 vocabulary rows were never looked
at, and the winner may not be within a thousand ranks of the actual argmax.

### 3. Unrestricted next-token argmax

Run the **original prompt**, with nothing appended. Take the complete
next-token distribution at the final prompt position. The argmax over the whole
vocabulary is the model's next token.

`jlens.mmpilot.full_vocabulary.score_unrestricted_next_token`.

**What it licenses.** "The model's next token is X." Under an intervention
applied during that same forward pass: "the intervention changed the model's
next token from X to Y."

**This is the endpoint Anthropic's systematic evaluation reports.** Their
spider→ant swap changes the top output token from `8` to `6`; a failed trial
reports the target token's rank in the full vocabulary. Success is counted only
when the target-appropriate token is global rank 1.

### 4. Global token rank

The same distribution as (3), read for a *specific* token: how many vocabulary
rows outscore it.

`jlens.mmpilot.full_vocabulary.tie_aware_ranks`, and
`jlens.mmpilot.convergence.tie_aware_ranks` for the lens work.

**What it licenses.** A graded statement about how close the model came. Rank 3
of 262,144 is a strong finding; rank 40,000 is not, and both are honest.
Optimistic, pessimistic and midranks are recorded separately, because a rank
that only looks like 1 because of ties is not a top-1.

**What it does not license.** A success. Rank 2 is not rank 1. Only a **unique**
global maximum counts.

### 5. Greedy generation

Temperature 0, no sampling, a fixed small budget; record the tokens the model
actually produced.

`jlens.mmpilot.full_vocabulary.greedy_generate`.

**What it licenses.** A demonstration. It is what a reader wants to see, and it
is the least statistically useful of the five: one completion per trial, with a
normalization rule that must be frozen before the completions are read (it is —
`GREEDY_MATCH_RULE`).

**What it does not license.** A verdict. Greedy text alone never establishes a
causal claim in this project.

## Why (2) and (3) can disagree completely

Nothing forces the winner of a two-way forced choice to be anywhere near the
global argmax. After `Answer:` the model's actual next token may be a newline, a
space, an end-of-turn marker, `The`, or a token belonging to neither candidate.
`two` outranking `four` is then a statement about two rows of a 262,144-row
distribution and says nothing about the other 262,142.

The corrected study therefore records both on the same population, and the MOCK
suite contains a world (`restricted_only`) in which the restricted endpoint
passes everywhere and the unrestricted endpoint passes nowhere. That world must
return `FULL_VOCAB_REASONING_NO_GO`, and a test asserts it.

## Single-token answers, and why multi-token answers are refused

A global argmax is a statement about **one** vocabulary row. There is no global
top-1 for `" mi|cro|wave"`. Two wrong ways to proceed and one right one:

* comparing its complete-sequence likelihood against single-row probabilities —
  those are not the same quantity;
* scoring only its first token — that silently compares prefixes, so `bus` and
  `bu|s` become the same candidate;
* **recording it as unsupported for the unrestricted endpoint and reporting it
  separately as a sequence-likelihood diagnostic** — which is what
  `resolve_answer_token` and `answer_token_table` do.

`two`, `four`, `bird` and `cat` are *required* to be single tokens: if any of
them is not, the reasoning experiment is refused before any model spending
rather than narrowed after the fact.

## The digit lexicalization correction is a new confirmation, not an amendment

The completed unrestricted rerun froze the word rows `two` and `four`. Its
greedy demonstrations subsequently showed that Gemma naturally answers this
prompt with the digit rows `2` and `4`. The resulting
`FULL_VOCAB_REASONING_NO_GO` is therefore a valid null for those exact word
rows, but it does not adjudicate whether the task-appropriate digit became the
model's output.

The first digit confirmation answered that different question with alpha=2 as
its primary intervention. That completed run remains immutable and is a valid
null for the amplified exchange: its direct-answer positive control also
failed, so it did not establish that the exact exchange was absent.

`multimodal_jspace_digit_reasoning_confirmation_colab.ipynb` now implements a
separately fingerprinted v3 study. V2 stopped before intervention because one
capability cell recruited 7 of its required 8 examples from 24 candidates. V3
therefore expands only the predeclared fresh candidate pool to 64 per concept,
keeps the eight-example causal cells and every causal setting unchanged, and
excludes the completed v2 population. It uses alpha=1 as the primary and only
nonzero strength; checks the complete vocabulary and a one-token greedy
continuation; requires the direct-answer arm and hidden-animal arm to beat
matched alpha=1 controls in both directions and every modality; and makes the
recorded exact-coordinate update a verdict gate. It never rewrites,
reinterprets or reuses any completed population.

For the pinned Gemma tokenizer, these are the **bare** digit rows. A leading
space followed by a digit encodes as two tokens, so the endpoint resolver uses
`leading_space=False` and separately verifies that each resulting row decodes
exactly as `2` or `4`.

## Which completed experiment measured which

| study | endpoint | survives |
| --- | --- | --- |
| spoken-audio feasibility / audit | engineering | unchanged |
| behavioral capability gate | **restricted-candidate** (6 options, all named in the prompt) | narrower wording |
| J-lens calibration and confirmation | **unrestricted next-token / global rank** | unchanged |
| native direct readout | **unrestricted next-token / global rank** | unchanged |
| J-space retrieval and shuffled controls | representational | unchanged |
| original multimodal pilot | **conditional log-probability** | narrower wording |
| robustness and layer localization | **conditional log-probability** | narrower wording |
| native spoken-audio transfer (`THREE_MODALITY_GO`) | **conditional log-probability** | narrower wording |
| single-layer paper-style reasoning swaps | **restricted-candidate** (2 options) | narrower wording |
| L33-L40 band follow-up | **restricted-candidate** (2 options) | narrower wording |
| band corrected control (lens validation) | **unrestricted / global rank** | unchanged |
| output convergence audit / L32 resolution | **unrestricted / global rank** | unchanged |

The pattern is worth stating plainly: **the lens work always measured the
unrestricted endpoint; the behavioral and causal work never did.** That is why
the lens validations, the layer band L33-L40, and the convergence results are
untouched by this correction, and why the causal verdicts are relabelled.

## The corrected labels

Until the corrected experiment runs, a completed behavioral or causal result
carries one of:

`RESTRICTED_CANDIDATE_PREFERENCE_GO`
: A forced-choice preference among the supplied candidates cleared its controls.

`CONTROLLED_TARGET_LOGPROB_EFFECT`
: A controlled change in the target answer's conditional log-probability. Real,
  causal, and not autonomous output.

`FULL_VOCABULARY_NOT_EVALUATED`
: The unrestricted question was never asked. Not a failure and not a pass.

These are added *beside* the original verdict strings by versioned amendments
(`jlens.mmpilot.endpoint_amend`), which recompute nothing:
`scientific_recompute = 0`, and every original report and unit is byte-identical
afterwards.

## Words that are prohibited for a restricted-candidate result

- "the model answered" / "the model's answer"
- "the model's output"
- "global top-1"
- "full-vocabulary"
- "paper-comparable"

`jlens.mmpilot.endpoint_audit.scan_active_sources` greps the modules that
compute restricted-candidate or conditional-log-probability endpoints for
exactly these, and the audit **fails** if one appears without an explicit
endpoint qualifier nearby. Modules that genuinely measure the whole vocabulary
are entitled to those words and are out of the scan's scope by construction —
the scope is derived from the registry, not hand-listed.
